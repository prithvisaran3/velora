# P2 — The 3D layer

Build the six moments in `docs/3D-MOTION.md`, in that order, each behind a flag and each shipped separately.
Visual reference: the first section of `design/Velora Website v2.dc.html`.

Install: `three`, `@react-three/fiber`, `@react-three/drei`. Nothing else — no physics engine, no postprocessing
stack, no HDR downloads.

## Foundation first (do not skip)

`src/three/` :

```
CanvasProvider.tsx   one <Canvas> for the whole site, mounted after LCP, kept across routes
tier.ts              'high' | 'mid' | 'low' from hardwareConcurrency, deviceMemory, pointer, 12-frame probe
useScene.ts          registers/disposes a scene in the shared canvas
materials/silk.ts    anisotropic sheen shader + zari mask material
scenes/…             one folder per moment, each exporting { Scene, Poster }
```

Mount rule: create the canvas only after the hero `<img>` `onLoad` **and** an idle callback, and never on
`low` or `prefers-reduced-motion`. Every route renders `Poster` first; `Scene` swaps in with an identical box so
there is zero layout shift.

## The six moments

1. **Vel loader** — extruded mark, 0.6 turn, specular sweep along the spine, settle flat, saffron fabric wipe. 900ms hard cap, first visit only.
2. **Hero cloth** — 24×24 verlet cloth, silk sheen shader, zari mask sharper than the ground; falls and settles in 1.4s, then pointer influence ≤ 0.15 units with 400ms smoothing.
3. **Colour dye** — same mesh across `/colour/[slug]`; lerp base + sheen colour over 800ms; zari stays gold; zero extra bytes per colour.
4. **PDP drape + macro loupe** — shared abstract form GLB (≤400 KB) + per-saree 2K textures; orbit clamped ±40°; loupe as a 512² render target at 3× narrower FOV, 250px circle, 2px marigold edge, 220ms lag; tap-and-hold on mobile. The flat-lay hero stays a plain `<img>`.
5. **Pallu unroll** — plane bent round a cylinder via one `uUnroll` uniform, GSAP ScrollTrigger pinned ≤120vh, annotations at 0.25 / 0.55 / 0.85. Desktop `high` only, dynamic import.
6. **Add-to-bag flight + zari weave** — FLIP-measured 2-fold plane arcing to the bag over 720ms then a marigold pulse; stepper segments drawn warp-then-weft over 900ms, once per status change (`lastSeenStatus` in localStorage).

## Guardrails

- Total three + scenes ≤ 220 KB gzip on the first interactive route. Report the number in the PR.
- Dispose geometries, materials and render targets on unmount; 20 route changes must leak no context (test it).
- DPR clamped: 1.75 high, 1.25 mid. Frame budget 16ms high, 33ms mid.
- If a moment cannot hold 30fps on a throttled mid-range Android, ship its poster and tell me — do not ship a
  janky scene.
- No moment may move the LCP element or delay it. Measure on the deployed preview, not localhost.

## Acceptance

- All six run on `high`; `mid` shows only hero + dye; `low` shows posters and creates no canvas.
- `prefers-reduced-motion` ⇒ no canvas anywhere.
- LCP < 2.5s and CLS < 0.05 on throttled 4G for `/` and a PDP, with the scenes live.
- Posters render with JS disabled.
- PR includes: bundle delta, measured LCP before/after, a 10s screen recording of each moment.
